# תמ"ל/1095/ב – מפת חומר ביסוס

Статическая страница: карта חלקות проекта с раскраской по году חומר ביסוס и выключением hatch по חלקות.
Статус вкл/выкл хранится в Supabase и синхронизируется между компьютерами сразу.

## Настройка Supabase (один раз)
1. supabase.com → New project.
2. SQL Editor → вставить содержимое `supabase.sql` → Run.
3. Project Settings → API: скопировать **Project URL** и **anon / publishable key**.
4. Вписать их в `config.js` → commit/push.

Без заполненного `config.js` страница работает как раньше: статус в браузере + `state.json`.

## Как работает сохранение
- Клик → статус сразу пишется в таблицу `parcel_status` и через Realtime появляется во всех открытых вкладках.
- Нет интернета → изменения копятся в браузере (видно «ждут отправки») и уходят автоматически, когда связь вернётся.
- Первое подключение к пустой таблице: то, что уже было выключено в этом браузере, загружается в базу автоматически.
- «Скачать state.json» — резервная копия; «Загрузить…» — восстановить из неё.

Доступ без входа: ключ виден в коде страницы, поэтому менять статусы может любой, у кого есть ссылка.

## Файлы
- `index.html`, `app.js`, `style.css` — страница
- `config.js` — подключение к Supabase
- `supabase.sql` — создание таблицы, доступа и Realtime
- `data.js` — геометрия и атрибуты חלקות (ITM → WGS84, упрощение 0.15 м)
- `state.json` — резервный файл статуса (режим без Supabase)
- `vendor/` — Leaflet 1.9.4 (BSD-2-Clause), supabase-js 2.119.0 (MIT)
